What the pipeline decides

Global rule

Keep useful city choices

Capitals and administrative seats are retained; ordinary populated places need at least 50,000 residents.

China rule

Stop at prefecture level

A pinned administrative policy excludes districts, counties, and county-level cities from the city selector.

Quality gate

Fail on ambiguity

The build checks parent links, coordinates, policy sentinels, and normalized duplicate display names.

Build it yourself

With Python 3.11 or newer, clone the repository and build the pinned snapshot. The output includes compressed CSV, SQLite, a quality report, and a self-contained browser.

git clone https://github.com/ALVIN-YANG/geonames-major-cities.git
cd geonames-major-cities
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .

geonames-major-cities all \
  --manifest manifests/geonames-2026-09-17.json \
  --data-dir data \
  --output-dir output
